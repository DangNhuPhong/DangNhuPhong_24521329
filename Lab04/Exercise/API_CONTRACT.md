# Forum API Contract

## Channels

nasa, esports-tribunal, notNasa.
Channel IDs are case-sensitive.

## GET /api/forums/:forumId/messages

200: Message[]
404: { error: string }

## POST /api/forums/:forumId/messages

Body:
{
"author": "string",
"text": "string"
}

Validation:

- Author: trimmed, 2–40 characters.
- Text: trimmed, 1–500 characters.
- ID and timestamp are generated by the server.

Responses:

- 201: created Message
- 400: invalid payload
- 404: unknown channel
- 413: body too large
- 500: unexpected server error

## Message

{
"id": "UUID",
"author": "string",
"text": "string",
"timestamp": "ISO date string"
}

## Alias

/api/messages/:forum supports the same GET/POST behavior.
