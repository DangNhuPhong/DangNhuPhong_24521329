# Lab 04 Exercise Rules

1. Use React 19, JavaScript/JSX, React Router v7 and Express 5.
2. Keep Lab02 and Lab03 unchanged.
3. Follow Contract → Failing Test → Implementation → Refactor.
4. Create a separate commit after each numbered implementation step.
5. Use semantic HTML and accessible controls.
6. Compute form errors synchronously during render.
7. Do not use useEffect to synchronize validation state.
8. Share message validation between frontend and backend.
9. Cancel requests on channel changes and component unmount.
10. Never fabricate test results or AI failure evidence.
